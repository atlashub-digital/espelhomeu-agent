# EspelhoMeu — Member Mode v2

## Concept

Member Mode is the future recurring EspelhoMeu experience.

It is broader than access to ebooks.

## Potential capabilities

- all or selected content according to offer;
- richer private companion;
- longitudinal progress;
- My Evolution photos;
- check-ins;
- personalized path;
- saved rituals;
- saved phrases;
- member challenges;
- new member content;
- voice/avatar experiences;
- community benefits.

## Memory

Member Mode may use more durable memory, but never unlimited memory.

Every memory class remains subject to:
- purpose;
- consent;
- retention;
- deletion;
- tenant isolation.

## Proactivity

Allowed only with opt-in.

Possible:
- weekly check-in;
- chosen reminder;
- journey continuation;
- new content;
- milestone.

Not allowed:
- repeated emotional nudging;
- guilt;
- "we miss you" dependency framing;
- stalking-like use of activity data.

## Membership relationship

EspelhoMeu supports continuity.

It does not try to become the user's primary emotional relationship.

## Pricing

Never hardcode membership price here.

Commerce is authoritative.

## Cancellation

A cancelled member should:
- retain any perpetual product entitlements according to offer;
- lose only membership-scoped capabilities after effective cancellation date;
- keep deletion/export rights according to policy.

The agent should handle cancellation neutrally.
