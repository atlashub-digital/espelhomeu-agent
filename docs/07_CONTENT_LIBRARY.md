# EspelhoMeu — Initial Content Library

This file is a seed bank, not the final editorial calendar.

The objective is to establish repeatable content categories for:
- WhatsApp community;
- private companion;
- social posts;
- carousels;
- stories;
- audio;
- future avatar video.

# 3. Gentle challenges

### 5 minutos por mim
Escolha cinco minutos do dia para um gesto que seja só seu.

### Foto sem julgamento
Tire uma foto hoje com uma regra: não decidir se ficou "boa" ou "ruim". Apenas registrar.

### Um detalhe
Escolha um detalhe de roupa, cabelo ou acessório que faça você se sentir mais presente.

### Espelho curioso
Olhe para si por 30 segundos procurando três coisas observáveis, sem adjetivos de valor.

### Pequeno recomeço
Retome uma prática que você abandonou, mas reduza para a menor versão possível.

### Minha cor
Use uma cor que você gosta e repare como se sente ao longo do dia.

### Sem corrigir
Passe um momento diante do espelho sem ajeitar nada nos primeiros 20 segundos.

### Uma escolha minha
Faça hoje uma pequena escolha estética sem perguntar se outra pessoa aprovaria.

### Movimento de presença
Caminhe por dois minutos prestando atenção apenas à postura e à respiração.

### Guardar uma frase
Escolha uma frase desta semana para levar com você.

# 4. Check-ins

- Como você está se vendo hoje?
- Quer observar, experimentar ou simplesmente conversar?
- Quer continuar de onde parou ou escolher outro ponto?
- Hoje você prefere um passo pequeno ou uma pausa?
- Tem algo que mudou desde a última vez?
- Quer registrar este momento na sua evolução?
- O que você gostaria de levar do encontro de hoje?
- Quer que eu te mostre uma ideia simples para hoje?
- Há algo que você quer preservar, não mudar?
- Qual foi o gesto mais seu desta semana?

# 5. Restart prompts

# 7. Ritual seeds

## Ritual do Espelho — 2 minutos
1. Respirar.
2. Observar sem ajustar.
3. Escolher uma palavra para o momento.
4. Fazer um gesto de cuidado.

## Ritual de Presença
1. Ombros relaxados.
2. Respiração natural.
3. Pés firmes.
4. Olhar no horizonte.
5. Pergunta: "Como quero ocupar meu espaço hoje?"

## Ritual de Fechamento
1. O que percebi?
2. O que escolho guardar?
3. O que posso deixar para amanhã?

## Ritual de Rosto — relaxamento
- mãos limpas;
- toque suave;
- sem dor;
- movimentos lentos;
- interromper em caso de desconforto;
- não usar como tratamento médico/estético.

# 9. Social carousel concepts

### Carousel: 5 maneiras de olhar para si sem julgamento
1. Observe antes de avaliar.
2. Descreva antes de comparar.
3. Repare no que escolheu.
4. Pergunte como se sente.
5. Decida se quer mudar — ou não.

### Carousel: Você não perdeu o ritmo
1. Pausar não apaga.
2. Retomar não exige compensar.
3. Pequeno também conta.
4. Seu caminho não precisa ser linear.
5. Voltar também é continuar.

### Carousel: Experimentar sem obrigação
1. Um cabelo diferente.
2. Uma cor.
3. Uma peça.
4. Um hábito.
5. Uma maneira nova de se olhar.

# 12. Content governance

Every reusable content item should eventually carry:
- content id;
- category;
- audience/channel;
- locale;
- risk level;
- source/editorial owner;
- reviewed version;
- entitlement/public status;
- expiry/review date when needed.

This seed bank may inspire content, but it does not override canonical AMF editorial products.
